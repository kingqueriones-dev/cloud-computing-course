# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform, commonly called GCP, is a cloud computing service provided by Google. It allows organizations to use computing power, storage, databases, networking, artificial intelligence, and other technologies through the internet. GCP is widely used for modern applications, data processing, and machine learning projects.

## Global Infrastructure

Google Cloud operates data centers in many regions and zones around the world. This global infrastructure allows organizations to place applications and data closer to their users while improving performance, reliability, and availability.

## Cloud Management Console

The Google Cloud Console is an online dashboard used to create and manage GCP resources. Users can manage virtual machines, storage, databases, networking, security settings, and other Google Cloud services through the console.

## Four Core Services

1. **Compute Engine** – Provides virtual machines for running applications and operating systems in Google Cloud.
2. **Cloud Storage** – Stores files, backups, media, and other types of data online.
3. **Virtual Private Cloud (VPC)** – Provides networking that connects and protects Google Cloud resources.
4. **Cloud Identity and Access Management (IAM)** – Controls who can access cloud resources and what actions they are allowed to perform.

## Three Advantages

1. Google Cloud provides powerful tools for artificial intelligence and machine learning.
2. It has strong support for Kubernetes and container-based applications.
3. Its global network can support applications that serve users from different locations.

## Typical Enterprise Use Cases

Companies can use Google Cloud for data analytics, artificial intelligence, machine learning, application hosting, cloud storage, database systems, Kubernetes deployments, and large-scale data processing.
