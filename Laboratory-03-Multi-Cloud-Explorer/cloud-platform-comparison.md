## Comparison Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers the broadest variety of cloud services among the three platforms. It supports many areas such as computing, storage, databases, networking, security, analytics, application development, and artificial intelligence.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the best option for organizations that already use Microsoft technologies. It works closely with products such as Windows Server, Microsoft 365, Active Directory, and other Microsoft enterprise solutions.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud Platform is particularly strong in Artificial Intelligence and Kubernetes. Its services are well suited for machine learning, data processing, and containerized applications through technologies such as Vertex AI and Google Kubernetes Engine.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Microsoft Azure because many schools and businesses already use Microsoft products. I think learning Azure would be useful because it combines cloud computing with familiar technologies such as Windows Server, Microsoft 365, and identity management.
