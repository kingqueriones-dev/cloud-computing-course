# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform from Microsoft that provides online resources for businesses, developers, schools, and other organizations. It can be used to run applications, store information, manage networks, host databases, and support different business systems without requiring all equipment to be located on-site.

## Global Infrastructure

Azure provides cloud services through data centers located in different regions around the world. Many Azure regions use Availability Zones, which separate resources across independent locations to help applications remain available when problems occur in one location.

## Cloud Management Console

The Azure Portal is the browser-based dashboard used to manage Microsoft Azure. From the portal, users can create virtual machines, configure storage, manage networks, monitor resources, and control access to cloud services.

## Four Core Services

1. **Azure Virtual Machines** – Allows users to create Windows or Linux virtual servers in the cloud.
2. **Azure Blob Storage** – Stores documents, images, backups, videos, and other unstructured data.
3. **Azure Virtual Network** – Creates private networks where Azure resources can communicate.
4. **Microsoft Entra ID** – Helps organizations manage user accounts, authentication, and access permissions.

## Three Advantages

1. Azure works well with many existing Microsoft products and services.
2. It supports both cloud-only and hybrid environments.
3. Organizations can scale their cloud resources based on changing workloads.

## Typical Enterprise Use Cases

Organizations can use Azure for business application hosting, Windows Server workloads, cloud backups, database management, identity management, disaster recovery, virtual desktops, and hybrid cloud systems.
