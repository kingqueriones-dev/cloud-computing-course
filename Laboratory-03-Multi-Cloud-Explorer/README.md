# Laboratory 03 - Multi-Cloud Explorer

## Linux Server Investigation

For this activity, I used the KillerCoda Ubuntu Playground to examine the basic hardware and operating system information of a Linux environment.

### System Details

* **Operating System:** Ubuntu 24.04.4 LTS (Noble Numbat)
* **CPU Information:** 1 vCPU, Intel Xeon E312xx (Sandy Bridge), x86_64 architecture
* **Memory:** 1.9 GiB total, 410 MiB used, 1.5 GiB available
* **Disk Space:** 19 GB total, 5.4 GB used, 13 GB available

## Possible Cloud Hosting Services

If this Linux server were transferred to the cloud, each major cloud provider has a virtual machine service capable of hosting it.

| Cloud Provider        | Suitable Service       |
| --------------------- | ---------------------- |
| Amazon Web Services   | Amazon EC2             |
| Microsoft Azure       | Azure Virtual Machines |
| Google Cloud Platform | Compute Engine         |

These services allow a Linux operating system to run on virtual computing resources instead of physical hardware. The amount of CPU, memory, and storage can also be selected or adjusted depending on the requirements of the server.
