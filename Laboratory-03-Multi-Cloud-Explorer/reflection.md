# Mission Reflection

Among the three cloud platforms, Microsoft Azure impressed me the most. I like how it connects cloud computing with technologies that many organizations already use, especially Windows Server, Microsoft 365, and identity services. I also found its support for hybrid cloud environments interesting because companies do not always need to move everything to the cloud at once.

AWS, Microsoft Azure, and Google Cloud Platform have many similarities. All three provide services for virtual machines, storage, networking, databases, identity management, security, and application development. They also allow organizations to increase or reduce resources depending on their workload, which makes cloud computing flexible compared with relying only on physical servers.

Business requirements have a major influence on choosing a cloud platform because every organization has different needs. A company using Microsoft products may benefit more from Azure, while an organization focused on artificial intelligence may prefer Google Cloud. AWS may be a better choice for companies that need a large variety of cloud services and global infrastructure.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider requires more than simply comparing service names. I learned to consider the client's existing technology, budget, expected growth, type of workload, and future goals before making a recommendation. This helped me understand how technical decisions should support business needs.

My GitHub Cloud Computing Portfolio also improved after completing this activity. It now contains organized research, cloud service comparisons, client recommendations, screenshots, and a Linux investigation using KillerCoda. I also became more comfortable using Markdown files and documenting technical activities in GitHub. Overall, this mission helped me better understand how AWS, Azure, and GCP can be used for different types of organizations.
