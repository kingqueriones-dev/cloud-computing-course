# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud platform created by Amazon that allows individuals and organizations to use computing resources over the internet instead of relying only on physical hardware. It supports many types of workloads, including websites, mobile applications, databases, backups, and enterprise systems.

## Global Infrastructure

AWS organizes its infrastructure into geographic Regions and Availability Zones. AWS currently has 39 Regions and 123 Availability Zones worldwide, helping customers deploy systems closer to their users and design applications with higher availability.

## Cloud Management Console

The AWS Management Console is the web interface used to access and control AWS services. It gives users one place to manage cloud resources, check account information, monitor services, and configure different AWS products.

## Four Core Services

1. **Amazon EC2** – Provides virtual servers that can run operating systems and applications.
2. **Amazon S3** – Stores files and other data as objects in the cloud.
3. **Amazon VPC** – Creates an isolated network where AWS resources can communicate securely.
4. **AWS IAM** – Manages users, roles, permissions, and access to AWS resources.

## Three Advantages

1. AWS has many different cloud services that can support different types of projects.
2. Its worldwide infrastructure allows businesses to serve customers in different locations.
3. Customers can increase or reduce resources as their workloads change.

## Typical Enterprise Use Cases

Businesses can use AWS to host websites and applications, store backups, run databases, support disaster recovery, process large amounts of data, and operate systems for customers in different countries.
