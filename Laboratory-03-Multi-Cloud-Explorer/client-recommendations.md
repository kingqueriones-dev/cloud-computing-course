# Client Recommendations

## Client A – Startup Company

**Recommended Platform: Google Cloud Platform (GCP)**

Google Cloud Platform is a good choice for the startup because it supports flexible cloud resources that can grow together with the mobile application. The company can begin with smaller resources and increase capacity as more users join. GCP also provides managed services that can reduce the amount of infrastructure the startup needs to maintain.

**Services:**

* Compute Engine
* Cloud Storage
* Cloud SQL
* Google Kubernetes Engine (GKE)

---

## Client B – University

**Recommended Platform: Microsoft Azure**

Microsoft Azure is the most suitable option because the university already uses Microsoft technologies such as Windows Server, Microsoft 365, and Active Directory. Azure can make the migration easier because it connects well with Microsoft-based systems. It can also support a hybrid setup where some services remain on campus while others are moved to the cloud.

**Services:**

* Azure Virtual Machines
* Microsoft Entra ID
* Azure Blob Storage
* Azure Virtual Network

---

## Client C – AI Research Company

**Recommended Platform: Google Cloud Platform (GCP)**

Google Cloud Platform is a strong choice for this company because it offers advanced artificial intelligence and machine learning tools. It also provides high-performance computing resources that can be used for demanding research workloads. The company can use GCP to train machine learning models, store research data, and deploy AI applications.

**Services:**

* Vertex AI
* Cloud TPU
* Compute Engine
* Cloud Storage

---

## Client D – Global E-Commerce Company

**Recommended Platform: AWS**

AWS is a suitable platform for the global e-commerce company because it provides infrastructure in many locations around the world. Its scaling and load-balancing services can help the website remain available when customer traffic suddenly increases. AWS can also support databases, product files, and content delivery for users in different countries.

**Services:**

* Amazon EC2
* Elastic Load Balancing
* AWS Auto Scaling
* Amazon RDS
* Amazon CloudFront
