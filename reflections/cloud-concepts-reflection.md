# Cloud Concepts Reflection

Before taking this Cloud Computing course, I honestly didn't realize how much I depended on cloud services every day. I thought 
apps like Google Drive and Messenger were just normal applications that made life easier. As we discussed cloud computing in 
class, I realized that these services are actually powered by the cloud and play a big role in how I study, communicate, and 
stay organized.

One of the cloud services I use almost every day is **Google Drive**. I save my assignments there because I don't have to worry 
about losing my files, and I can open them using my laptop or phone anytime. Google Drive is an example of **Software as a Service
(SaaS)** because I only use the application while Google manages everything behind it. It is also part of the **Public Cloud** 
since anyone with a Google account can use it. Another service I always use is **Facebook Messenger**. It's also a **SaaS** 
application on a **Public Cloud** because it lets people communicate online without needing to install or manage any servers. 
Lastly, I use **Canva**, especially when making presentations, posters, and school projects. Since it is available online and 
can be accessed by anyone with an account, it is also classified as **SaaS** and runs on a **Public Cloud**.

Learning about Git and GitHub was something new for me. At first, I thought they were only for professional programmers, but now 
I understand why they are important. Version control helps keep track of every change made to a project, so it's easier to fix 
mistakes or go back to an earlier version if needed. GitHub also makes teamwork more organized because everyone can work on the 
same project without overwriting each other's files. I believe these skills will be useful not only in this subject but also in 
my future career in the IT industry. This activity made me appreciate how cloud computing and version control work together to 
make technology more reliable, efficient, and easier to use.
